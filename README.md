## 📖 Overview

Imagify is a full-stack AI SaaS platform that enables users to generate high-quality images from text prompts using advanced generative AI models. The application features secure authentication, a credit-based usage system, online payments, and a responsive user interface designed for a seamless creative experience.

Built with the MERN Stack, Imagify demonstrates the integration of AI services with modern web technologies, allowing users to transform their ideas into visually compelling images within seconds.

## 🖼️ How It Works

1. User creates an account or logs in.
2. User enters a text prompt describing the desired image.
3. The backend sends the prompt to the ClipDrop AI API.
4. AI generates a high-quality image.
5. Generated image is returned to the user.
6. Credits are deducted automatically.
7. Users can purchase additional credits when needed.
